# JANUS Crux

Tema descargable para Windows inspirado en la estética clásica Crux de GNOME/MATE y adaptado por JANUS.

Incluye variantes clara y oscura, fondos 4K y ultrapanorámicos 5K, colores coordinados, cursores propios y sonidos discretos opcionales. El color de énfasis es naranjo `#E87817`.

Los iconos se distribuyen como complemento separado y conservan su atribución y licencia originales. JANUS respalda la configuración antes de aplicar cambios y permite restaurar el tema anterior.

El paquete no reemplaza archivos protegidos de Windows y no requiere parches del sistema.
