# JANUS Newaita

Tema claro inspirado en paisajes naturales de Alaska y Noruega, con tres momentos del mismo fiordo: mañana despejada, cielo nublado con luna y noche estrellada.

Incluye fondos para pantallas 16:9 y ultrapanorámicas, color de énfasis turquesa, cursores orgánicos propios y sonidos discretos. Los sonidos de inicio, inicio de sesión, cierre de sesión y salida se registran únicamente mediante el esquema normal y reversible de Windows; su reproducción automática depende de la versión y configuración del sistema.

El complemento de iconos Newaita se distribuye en un ZIP separado. JANUS respalda los valores actuales antes de aplicar el tema y no reemplaza archivos protegidos de Windows.
